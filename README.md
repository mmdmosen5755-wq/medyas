# 🤖 ربات ارسال و زمان‌بندی ایتا (ایتایار) — نسخه تجاری

ربات تلگرام + پنل وب برای فروش سرویس «ارسال و زمان‌بندی پست در کانال‌های ایتا» با API رسمی **eitaayar.ir**.

## امکانات
**برای کاربر (داخل ربات تلگرام)**
- ثبت توکن ایتایار خودش (رمزنگاری‌شده ذخیره می‌شود) + تست خودکار با `getMe`
- افزودن چند کانال/گروه
- ارسال متن، عکس، فیلم، صوت، ویس، سند، گیف (`.gif`) و استیکر ثابت (`.webp`) — دقیقاً مطابق مستندات
- ارسال فوری یا **زمان‌بندی** (تاریخ شمسی، `فردا 09:00`، `+45` دقیقه بعد…) به وقت تهران
- گزینه‌های ایتایار: عنوان، بی‌صدا (`disable_notification`)، سنجاق (`pin`)، حذف خودکار با تعداد بازدید (`viewCountForDelete`)
- لیست و لغو پست‌های زمان‌بندی‌شده، گزارش موفقیت/خطای هر ارسال
- خرید اشتراک کارت‌به‌کارت با رسید و تأیید ادمین

**برای شما (فروشنده)**
- پنل وب: توکن ربات تلگرام، آیدی ادمین، قیمت پلن‌ها، شماره کارت، دوره‌ی تست رایگان، متن خوش‌آمد
- مدیریت کاربران (تمدید، مسدود)، تأیید/رد پرداخت‌ها، آمار
- ادمین‌ها اشتراک نامحدود دارند و **توکن ایتایار خودشان را هم داخل ربات ثبت می‌کنند**
- دستورهای ادمین در ربات: `/user` `/adddays` `/ban` `/unban` `/broadcast`

## راه‌اندازی روی Railway
1. این پوشه را در یک ریپوی GitHub آپلود کنید (`.env` را هرگز آپلود نکنید).
2. در Railway: **New Project → Deploy from GitHub repo** و ریپو را انتخاب کنید.
3. **+ New → Database → PostgreSQL** اضافه کنید (برای ذخیره‌ی ماندگار اطلاعات؛ بدون آن با هر Deploy دیتا پاک می‌شود). متغیر `DATABASE_URL` خودکار به سرویس وصل می‌شود؛ اگر نشد، در Variables به‌صورت Reference اضافه‌اش کنید.
4. در **Variables** سرویس این دو متغیر را بگذارید:
   - `SECRET_KEY` = یک رشته‌ی تصادفی طولانی (مثلاً خروجی `python -c "import secrets;print(secrets.token_urlsafe(36))"`). **بعد از شروع تغییرش ندهید**، وگرنه توکن‌های ذخیره‌شده خوانا نمی‌شوند.
   - `ADMIN_PASSWORD` = رمز ورود به پنل وب
5. در **Settings → Networking → Generate Domain** آدرس عمومی بگیرید.
6. وارد آدرس سایت شوید → با `ADMIN_PASSWORD` وارد شوید → **تنظیمات**:
   - توکن ربات تلگرام (از @BotFather) و آیدی عددی ادمین (با `/id` از ربات یا @userinfobot) را وارد کنید.
   - قیمت‌ها و شماره کارت را بگذارید → **ذخیره**. ربات همان لحظه روشن می‌شود.
7. در ربات: «🔑 توکن ایتایار» → توکن خودتان را بدهید (از پنل eitaayar.ir).

> نکته‌ی تلگرام: ربات با long-polling کار می‌کند؛ فقط **یک نسخه** از سرویس را اجرا کنید (replica = 1).

## ⚠️ نکته‌ی مهم: دسترسی سرور خارج از ایران به ایتایار
سرورهای Railway خارج از ایران هستند. اگر `eitaayar.ir` درخواست IP خارجی را مسدود کند، ربات هنگام ثبت توکن خطای اتصال می‌دهد. راه‌حل‌ها (بدون تغییر کد):
- `EITAA_PROXY` = آدرس یک پروکسی HTTP با IP ایران (فقط تماس‌های ایتایار از آن رد می‌شوند)
- یا `EITAA_API_BASE` = آدرس رله‌ی خودتان روی سرور ایرانی که درخواست را به `https://eitaayar.ir/api` فوروارد کند.

این مورد را قبل از فروش با ثبت یک توکن تست کنید.

## ساختار
```
app/main.py       سرور FastAPI + راه‌اندازی ربات و زمان‌بند
app/bot.py        ربات تلگرام (aiogram 3)
app/eitaa.py      کلاینت API ایتایار (getMe / sendMessage / sendFile)
app/scheduler.py  حلقه‌ی ارسال پست‌های سررسیده (هر ۱۰ ثانیه، ۳ بار تلاش مجدد برای خطای شبکه)
app/web.py        پنل مدیریت  ·  app/templates/  قالب‌ها
app/db.py         مدل‌ها (SQLAlchemy؛ PostgreSQL یا SQLite)
```

## توضیحات فنی
- زمان‌بندی توسط خود سرور انجام می‌شود (نه پارامتر `date` ایتایار) تا برای فایل‌ها هم یکسان و قابل لغو باشد؛ پس از ری‌استارت، پست‌های نیمه‌کاره دوباره در صف قرار می‌گیرند.
- فایل‌های زمان‌بندی‌شده به‌صورت `file_id` تلگرام نگه‌داری و هنگام ارسال دانلود می‌شوند (حداکثر ۲۰ مگابایت، محدودیت تلگرام). با تعویض توکن ربات تلگرام، فایل‌های صف‌شده‌ی قبلی ارسال نمی‌شوند.
- توکن‌های ایتایار و توکن ربات با Fernet (کلید برگرفته از `SECRET_KEY`) رمز می‌شوند. پیام حاوی توکن در چت کاربر حذف می‌شود.
- متن پست به‌صورت ساده (بدون قالب‌بندی) ارسال می‌شود؛ مستندات ایتایار پارامتر قالب‌بندی ندارد.

## روبیکا
1. در روبیکا از @BotFather یک ربات بسازید و توکن را در پنل وب ← تنظیمات ← «ربات روبیکا» ذخیره کنید (یا متغیر `RUBIKA_BOT_TOKEN`).
2. کاربر در ربات تلگرام: «برنامه‌های متصل ← روبیکا» را باز می‌کند، ربات روبیکا را عضو و ادمین کانال می‌کند، «افزودن کانال» را می‌زند و آیدی کانال را می‌دهد.
3. اگر آیدی شناسایی نشد، گزینه‌ی «اتصال با کد» کدی می‌دهد که داخل کانال فرستاده می‌شود (نیاز به فعال‌بودن «دریافت همه پیام‌های کانال و گروه» در BotFather روبیکا).
4. روبیکا زمان‌بندی داخلی ندارد؛ پست‌های زمان‌بندی‌شده توسط صف خود برنامه ارسال می‌شوند.


## دستیار هوشمند محتوا (جدید)

**برای کاربر**
- دکمه‌ی «افزودن کانال محتوا»: در هر خط آیدی یا لینک کانال ایتا؛ ربات نام و تعداد عضو هر کانال را اعلام و ذخیره می‌کند.
- دکمه‌ی «دستیار هوشمند»: گفتگوی آزاد با یک عامل (agent) که موضوع کانال شما را یاد می‌گیرد، کانال‌های محتوا را زیر نظر دارد،
  تبلیغ و تکراری را حذف می‌کند، پست‌های مناسب را بازنویسی و (به انتخاب شما) **پیشنهاد با دکمه** یا **انتشار خودکار** می‌کند.
  از تأیید/رد شما سلیقه‌تان را یاد می‌گیرد. هر دستوری هم بدهید اجرا می‌کند («حالت خودکار روشن شود»، «فلان پست را ساعت ۹ بگذار»).

**برای مدیر (پنل وب ← تنظیمات ← «هوش مصنوعی» و «قوانین مدیر»)**
- کلید API (Claude یا هر سرویس سازگار با OpenAI)، دو مدل (هوشمند / ارزان)، کلید اضطراری خاموش‌کردن.
- قوانین به زبان ساده + کلمات ممنوعه + سقف‌ها. اگر کاربر خلاف قوانین چیزی بخواهد دستیار «نمی‌توانم» می‌گوید و به شما
  (ربات + صفحه‌ی «دستیار هوشمند») گزارش می‌دهد؛ تکرار ← تعلیق خودکار ۲۴ ساعته.
- دستورهای ادمین: `/srctest آیدی` (آزمایش خواندن یک کانال) · `/guardtest` (آزمایش قوانین با حساب خودتان؛ ادمین به‌طور پیش‌فرض معاف است).

**متغیرهای اختیاری Railway**: `ANTHROPIC_API_KEY` (یا کلید را در پنل بگذارید) · `AI_PROXY` · `EITAA_WEB_BASE` (رله‌ی خودتان اگر eitaa.com آی‌پی خارجی را ببندد؛ `EITAA_PROXY` هم برای خواندن کانال‌ها استفاده می‌شود).

ساختار جدید: `scraper.py` خواندن صفحه‌ی عمومی ایتا · `ai.py` اتصال AI · `policy.py` لایه‌ی قوانین · `curator.py` خط‌لوله‌ی بررسی خودکار · `agent.py` عامل گفتگویی · `agent_ui.py` رابط تلگرام · `tests/` تست‌ها (`pytest`).
